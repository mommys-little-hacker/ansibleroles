# Общий контекст для агентов

Этот файл содержит общий контекст проекта, важные решения и технические детали.

## Основной стек
- Ansible

## Ограничения на тестирование
- **Репозиторий — чистая коллекция ролей, плейбуков в нём нет.** Запускать
  плейбуки и роли (в том числе с `--check --diff`) не нужно и запрещено:
  проверка выполняется только статически.
- **Molecule-тесты не запускать.** Molecule-сценарии в репозитории пока не
  готовы и не поддерживаются. Ни агентам, ни QA не выполнять `molecule test`
  (ни по отдельным ролям, ни по проекту). При доработке molecule-сценариев
  данное ограничение будет снято отдельно.
- Допустимые проверки: `ansible-lint`, `yamllint`, статический анализ кода
  ролей (в том числе на идемпотентность и корректность логики).
  Инструменты для запуска (`ansible-run` и т.п.) не использовать.
