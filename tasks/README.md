## Статусы задач

- **Новая** - задача создана, ожидает начала разработки
- **Разработка** - задача в процессе реализации
- **Тестирование** - задача реализована, проходит тестирование
- **Готово** - задача завершена и протестирована
- **На доработке** - задача требует исправлений после тестирования

После перевода задачи в статус "Готово" ее необходимо перенести в [архив](ARCHIVE.md).
