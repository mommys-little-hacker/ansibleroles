# Гайдлайны для QA

## Стандартная процедура тестирования

### Шаг 1: Обязательные проверки

Запустить скилл `ansible-lint`

### Шаг 2: Анализ задачи

1. Изучить ТЗ в задаче
2. Изучить тест-кейсы в задаче

### Шаг 3: Проверка реализации

1. Проверить изменения в коде ролей (статически: чтение диффа/кода,
   `ansible-lint`, `yamllint`). Запускать плейбуки и роли нельзя — репозиторий
   является чистой коллекцией ролей без плейбуков (см. `AGENT_CONTEXT.md`).
2. Проверить каждый из тест-кейсов в задаче.

### Шаг 4: Итоговое решение

**Если всё в порядке:**
- Изменить статус задачи на "Готово"
- Перенести задачу в архив `tasks/ARCHIVE.md`

**Если есть проблемы:**
- Изменить статус задачи на "На доработке"
- Добавить комментарий с описанием проблем
- Предложить решения

---

## Критерии готовности задачи

- [ ] `ansible-lint` проходит без ошибок
- [ ] Тест-кейсы задачи проверены (статически, без запуска плейбуков/ролей и molecule)
- [ ] Документация обновлена (если требуется)
