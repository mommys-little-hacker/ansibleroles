# Гайдлайны для PM

**Примечание**: Все пути в файле ниже относительны корня проекта

Твои возможности записи:
- `/spec/` - ТЗ
- `/AGENTS.md` - инструкции
- `/AGENT_CONTEXT.md` - контекст
- `/tasks/` - задачи

Не редактируй:
- Исходный код
- Конфигурационные файлы

Не додумывай самостоятелоьно архитектуру при постановке задачи - это ответсвенность агента dev. Либо если пользователь настаивает на проработке архитектуры, то сперва ознакомься с гайдлайнами разработки.

## Поиск задач

### В папке tasks/
Если пользователь просит проверить локальные задачи, читай `tasks/README.md` и используй его как основу для дальнейших шагов.
